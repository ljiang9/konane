# konane（夏威夷跳棋）

极简版 Konane：8×8 交错摆子、正交跳吃、可连跳、无棋可走判负。纯 Python 标准库。

## 玩法

- 棋盘 8×8，黑白棋子交错摆放（黑 32 / 白 32），你是**黑方**先手。
- **开局**（简化规则）：黑方从中央 4 格取走一枚黑子，白方取走与空格正交相邻的一枚白子（AI 代下）。
- **行棋**：沿上下左右跳过一枚**相邻**的对方棋子，落到其后紧邻的空格，被跳过的棋子移除。
  一回合内可以连跳（允许转向），也可以提前停下。
- **胜负**：轮到你却无棋可跳时判负。

## 用法

```bash
python3 -m konane            # 人机对战（你是黑方）
python3 -m konane --auto --games 10 --seed 42   # AI 对 AI 自动演示
```

走法输入走法编号（如 `3`）；`q` 退出。坐标为 a–h 列 × 1–8 行。

## 真实验证记录

- `py_compile konane.py __main__.py`：通过。
- 16 项单元测试（`/tmp/test_konane.py`，真实执行，全过）：
  开局取子规则（黑只能取中央黑子、白只能取空格相邻白子、非法取子抛 ValueError）、
  单跳吃子移除对方棋子、连跳完整路径与提前停下前缀均合法、连跳吃掉两子、
  无棋可走判负、跳过己方/非跳步/错轮次行棋均被拒绝、AI 开局与第一步合法。
- `--auto --games 10 --seed 42`：10 局正常结束，黑方胜 5 / 白方胜 5。
- `--auto --games 5 --seed 7`：5 局正常结束，黑方胜 2 / 白方胜 3。

## 诚实局限

- AI 只是贪心（每步吃子最多），不做深层搜索；熟悉规则的人类通常能赢。
- 开局为简化版：传统 Konane 开局取子有多轮，这里只取两子。
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+。
